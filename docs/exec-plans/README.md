# Exec Plans (실행 계획)

여러 세션에 걸치는 작업(보통 모듈 하나 또는 그 하위 기능)을 시작하기 전에 계획을 쓰고, 진행하면서 갱신한다.
새 세션은 `active/`의 계획을 먼저 읽고 이어서 작업한다.

- 진행 중: `active/MN-짧은-제목.md` (예: `active/M2-expression-controller.md`)
- 끝나면 `completed/`로 옮긴다.
- 작은 수정(한 세션 안에 끝나는 것)은 계획 없이 진행한다.

## 템플릿

```markdown
# M?: 제목

- 상태: 진행 중
- 시작: YYYY-MM-DD

## 목표
끝났을 때 무엇이 동작해야 하나 (확인 방법 포함).

## 범위 밖
이번에 하지 않는 것.

## 단계
- [ ] 1. ...
- [ ] 2. ...

## 진행 로그
- YYYY-MM-DD: 한 일, 막힌 점, 다음 할 일

## 결정 사항
작업 중 내린 결정. 오래 남길 만하면 ADR로 승격한다 (`docs/adr/`).
```
