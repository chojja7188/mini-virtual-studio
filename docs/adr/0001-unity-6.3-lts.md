# 0001. Unity 6.3 LTS 사용

- 상태: 채택
- 날짜: 2026-11-24
- 모듈: M1

## 맥락
프로젝트를 처음에 Unity 6.6(`6000.6.7f1`, Supported)으로 만들었다. Hub의 Recommended는 6.6이지만 LTS가 아니다.
앞으로 UniVRM, Photon Fusion 2, Cinemachine 등 외부 패키지를 많이 쓸 예정이다.

## 결정
Unity 6.3 LTS(`6000.3.29f1`)로 내리고 고정한다. 프로젝트가 거의 비어 있는 지금 옮긴다.

## 검토한 대안
- Unity 6.6 (Supported): 최신 기능이 있지만 다음 버전이 나오면 지원이 끝나고, 외부 패키지 검증이 늦을 수 있다.
- Unity 6.0 LTS: 안정적이지만 6.3보다 오래돼 지원 종료가 먼저 온다.

## 결과
- 패키지 호환성과 장기 패치를 얻는다. 실무에서 흔한 LTS 환경과 같다.
- 6.4 이후 새 기능은 쓰지 않는다. 다음 LTS가 나오면 이 ADR을 다시 본다.
